# متجر SITA الإلكتروني

موقع عربي (RTL) كامل لمتجر SITA، مبني HTML/CSS/JS خالص بلا خادم أو قاعدة بيانات.
السلة والطلبات تُحفظ محلياً في متصفح العميل (localStorage) لأغراض العرض التجريبي.

## التشغيل
افتح `index.html` مباشرة، أو:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الصفحات
- الرئيسية، المتجر، ٤ صفحات منتجات، عن SITA، معايير الجودة، معجم المكوّنات.
- التغليف السري، الاستبدال والاسترجاع، الخصوصية، الشروط، الأسئلة الشائعة، تواصل معنا.
- السلة، الدفع، تأكيد الطلب، تتبّع الطلب، المدونة + ٤ مقالات.

## قبل النشر — مهم
1. استبدل `BASE` و`WHATSAPP` و`EMAIL` أعلى `build.py` بقيمك الحقيقية، ثم أعد تشغيل `python build.py`.
2. استبدل الأسعار في `PRODUCTS` بأسعارك الفعلية.
3. استبدل آراء العملاء (.search `SAMPLE REVIEWS`) بآراء حقيقية موثّقة.
4. حدّث قوائم المكوّنات بـ INCI المعتمد من جهة التصنيع.
5. راجع صفحات السياسات مع مستشار قانوني.
6. اربط بوابة دفع حقيقية في `checkout.html` بدل النموذج التجريبي.

## إعادة البناء
```bash
python build.py
```
يقوم المولّد بضغط الصور إلى WebP وإنشاء نسخة كاملة من كل الصفحات.
